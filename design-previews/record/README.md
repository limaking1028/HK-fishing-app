# 釣港「記錄」頁設計預覽

三個 HTML 都可以獨立開啟，內嵌樣式、示範資料及原有「黑鱲」魚種相。原型用假資料模擬定位、行程、潮汐、上榜及送出，所有互動都喺本機完成。

## A｜精簡單頁

魚種、重量同長度排喺最前，釣點同魚獲相緊接其後，熟手可以順住填。用分隔線整理區段，減少一層層卡片。把日期、時間、潮汐、釣法、釣餌、備註同磅相放入「更多資料」，行程中會展開畀用家確認帶入資料。上榜條件預設顯示一行摘要，固定底部送出掣方便隨時完成記錄。

## B｜分步填寫

將記錄拆成相片、魚獲、釣點同確認四步，每屏集中做一件事。頂部步驟可直接切換，返回時會保留之前輸入。磅相放喺相片步驟摺疊區，釣具資料同備註摺疊喺釣點步驟。確認步驟一次睇晒送出摘要同上榜條件，新手容易跟，但熟手每次記錄要多撳幾下。

## C｜相片優先

將魚獲相放喺第一張卡，放大影相同相簿掣，方便現場單手快速影低魚獲。揀相後原位顯示預覽，魚種、重量同釣點各自用清楚嘅卡片分組。磅相收喺相片卡，時間、潮汐、釣具及備註收喺釣點卡。相片佔用更多首屏空間，適合經常由影相開始嘅釣友。

## 推薦 A

A 保留單頁填寫嘅速度，亦減少畫面上嘅盒同重複提示。熟手可以快速填寫同連續記錄，新手可以按需要打開「更多資料」同上榜條件。相比 B 要換步驟、C 要先經過相片卡，A 進頁就見到魚種同重量，較適合做預設版。
